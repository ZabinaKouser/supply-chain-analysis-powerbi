# Supply Chain Demand vs Availability Analysis

## Objective
Analyze demand and supply mismatch to identify shortages and improve profitability.

## Tools Used
- Power BI
- SQL
- Excel

## Key Metrics
- Average Demand
- Average Availability
- Supply Shortage
- Profit & Loss

## Insights
- Demand exceeds supply in many cases
- Loss occurs due to unmet demand
- Some products contribute more to shortages

## How to Use
1. Download PBIX file
2. Open in Power BI Desktop
